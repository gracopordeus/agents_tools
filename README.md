# agents_tools

Ferramentas auxiliares usadas no desenvolvimento do simple-arpg.

Este repositório versiona os scripts e wrappers de ferramentas. Os seguintes
conteúdos permanecem locais por serem grandes, gerados ou dependências externas:

- `d2r-assets/`, `source-assets/` e `generation/`: armazenamentos de assets e
  saídas geradas;
- `d2r-casc/CascLib/`: dependência externa com histórico próprio;
- `pixel-asset-gen/` e `pixelmaker-godot-plugin/`: repositórios independentes;
- imagens e protótipos visuais na raiz e em `concepts/`.

Consulte os READMEs de cada ferramenta para instruções específicas.
